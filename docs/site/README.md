# Batch 11 · Khulna University — Web Platform

Static HTML/CSS mockup of the Batch 11 alumni platform, extracted from the
original single-file design export (`Batch 11 · Khulna University — Web
Platform.html`) into a plain multi-page project.

## Structure

```
site/
  index.html            Home (includes the "Supported by our sponsors" strip)
  members.html          Member directory
  events.html           Events (featured event shows a "Sponsored by" credit)
  gallery.html          Gallery & videos
  blog-post.html        Blog post detail
  business.html         Business Directory — alumni-run businesses
  business-detail.html  Single business profile
  signin.html           Sign in
  admin/
    dashboard.html       Admin dashboard
    members.html         Admin — manage members
    edit-post.html       Admin — edit blog post
    businesses.html       Admin — review/manage business listings
    sponsors.html         Admin — manage sponsor logos & tiers
  assets/
    css/
      fonts.css          Shared @font-face declarations (Fraunces, Instrument Sans)
      base.css           Global resets (body margin, link colors)
      responsive.css     Mobile layout (<=860px): nav/sidebar collapse, grid
                          stacking, font/padding scale-down — see DESIGN.md
      diamond-popup.css  Home-only welcome popup for the exclusive Diamond
                          sponsor (index.html only) — see DESIGN.md
```

## Notes

- This is a **visual mockup only** — no backend. Almost no JavaScript
  either: the mobile nav/sidebar toggles are pure CSS, and the *only*
  actual `<script>` on the whole site is the ~10-line sessionStorage
  check behind the Diamond popup's once-per-visit memory (see below).
  Everything else — search/filter controls, tab switches, form
  submissions — is inert. All data (member names, stats like `[000]`,
  photo placeholders) is sample/placeholder content from the original
  design.
- Pages are plain HTML with inline styles (as generated by the original
  design tool) plus shared stylesheets. Open any `.html` file directly in
  a browser — no build step or server required.
- Cross-page links (nav, "View public site", sign-out, etc.) have been
  rewritten to point at the real files in this structure.
- **Responsive**: below 860px, the public nav and admin sidebar collapse
  into a hamburger menu / off-canvas drawer (pure CSS, via a hidden
  checkbox + `<label>` — no JS), and all card grids, forms, and headline
  sizes reflow to a single mobile column. See `DESIGN.md` → "Mobile
  responsive layer" for how it's implemented on top of the inline-styled
  desktop markup.
- **Advertisement feature**: two parts, see `DESIGN.md` → "Advertisement
  feature (Sponsors + Business Directory)" for the full breakdown.
  Sponsors are committee-curated (Home strip, event credit, `admin/sponsors.html`)
  with no public submission flow. The Business Directory is alumni
  self-listed (`business.html`, gated behind sign-in to submit) and
  reviewed through the same approve/reject pattern as membership
  requests, in `admin/businesses.html` and the dashboard's "Business
  submissions" panel.
- **Diamond sponsor**: one exclusive top tier above Gold (currently
  Gollamari Coffee Roasters), which also gets a welcome popup on the
  Home page. Show/hide is pure CSS; a small inline script on `index.html`
  remembers dismissal for the browser session (`sessionStorage`) so it
  only shows once per visit — the **one** place this project uses
  JavaScript. See `DESIGN.md` → "Diamond welcome popup" / "Once-per-visit
  memory".
